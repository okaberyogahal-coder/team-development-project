# ワールドの戦闘モード

開始案内や各パネルを閉じ、3Dワールド内をクリックしてからFキーを押すと戦闘モードになります。もう一度Fを押すと解除します。レベルやアイテムなどの追加条件はありません。

- 左クリック：ビーム
- 右クリックを押している間：照準
- E：パンチ
- Enter：会話・入室
- Esc：パネルを閉じる／マウス固定を解除

開始案内、プロフィール、部屋のお題などのパネルが開いている間は、Fで切り替わりません。選択中のV3アバターの外見は維持されます。

## 今回の修正

PR #10の戦闘機能は`codex/avatar-integration`にマージされていましたが、起動中の`codex/replace-avatar-customizer`には含まれていませんでした。既存のお題20件、歩行ループ、くっきり表示の修正を保存したうえで、競合なく戦闘機能を統合しました。

統合後、シーンに保存するON/OFF値を使うと、実行時に戦闘コンポーネントが生成されないことを確認しました。その値をなくし、起動時に必ず初期化するよう変更しました。V3アバターをカメラ近くで一時非表示にした後、再表示しても歩行アニメーションが再開する修正も加えています。

## 検証

- 実WebGLを使ったブラウザーテスト：ゲスト／V3アバターでFのON/OFF、2件成功。
- Unity Editor：48件成功。
- Unity PlayMode：エフェクト解放、6体の継続歩行、再表示後の歩行復帰、3件成功。
- Webテスト：126件成功。TypeScript型チェックと追加テストのESLintも成功。

ブラウザーテストは`npm run test:combat`で実行します。Unity WebGLをキャッシュなしで再生成する場合は、`MELIFE_UNITY_CLEAN_BUILD=1 npm run build:unity`を使います。生成物はGit管理対象外で、このワークスペースのローカルWebGLには反映済みです。
