# 登録体験からUnity Worldへの入場

この導線はDB・認証サービスを使わない体験版。実際のアカウントを作成したり、メール・パスワードをサーバーへ送信したりしない。

1. TOPの「アカウントを作成」から既存の登録フォームへ進む。
2. 入力体験の完了時に、IDとニックネームをこのブラウザへ保存する。メール・パスワードは保存せずフォームから消去する。
3. 「3Dアバターを作成する」で `/avatar` を開く。Unityの実モデルと着替え画面を使い、服・色・髪型・小物を選ぶ。
4. 「このアバターで入場」を押すと、外見を保存して `/plaza` へ進む。Unity Worldへ同じ名前と外見を渡し、自動で入場する。
5. 再読み込みやログイン画面の「保存した体験を再開する」から、このブラウザの体験を続けられる。作成未完了ならアバター作成へ戻る。

`localStorage` の `melife.demo-profile.v1` にはバージョン、体験ID、ニックネーム、外見のみを保存する。外見は既存Unity着替えカタログのベースモデル・9部位の形・9部位の色・セット衣装に対応する。従来の6部位形式も読み込み、Unityで服と表情を引き継いで拡張形式へ変換する。別ブラウザ・別端末には同期されない。入力した学び・得意などの追加項目は現段階では保存しない。

Web/Unity間は同一オリジンのiframeの `postMessage` とUnity `SendMessage` で連携する。送信元ウインドウ、オリジン、体験IDと外見の範囲を確認する。IDは表示データを取り違えないための識別子であり、ログイン認証や権限チェックには使用しない。

アバター作成画面では入場を確定するまでWeb側の外見を完了扱いにしない。ワールド内のプロフィールで変更した外見と名前はWeb側の同じ体験プロフィールにも保存する。登録せずワールドを開いた場合はゲスト体験を残す。

Unityの変更後は `npm run build:unity` でWeb出力を再生成する。Webビルド出力はGit対象外。検証は `npm test`、`npx tsc --noEmit`、Unity EditModeの `FutureCity.Tests`、ブラウザでTOP→登録→アバター→入場→再読み込みを行う。
