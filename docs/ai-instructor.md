# AI講師のローカル検証

教材「自然光と背景ぼけの基本」の本文を読み、質問・やさしい説明・具体例・確認問題3問・復習を試す開発用の機能です。本文と問題は新規作成したサンプルです。本番公開・教材監修・正式な受講完了記録には未対応です。

## 起動と利用

1. `npm run dev:ai-instructor` を実行します。専用サーバーは `127.0.0.1:3004` で起動します。追加引数によるホスト変更は受け付けません。
2. `http://localhost:3004/login` で既存の開発用ユーザーにログインします。アカウントは `data/local-demo/README.md` を参照してください。
3. 同じブラウザ・ホストの `http://localhost:3004/ai-instructor` を開きます。
4. 本文と送信先の説明を確認して「学習を始める」を選びます。本文だけ読む場合は開始不要です。

文字チャットを使う場合は、サーバー用の `.env.local` に `OPENAI_API_KEY` と `OPENAI_MODEL` を設定して再起動します。構造化出力に対応した利用可能なモデルIDを指定してください。モデルは自動選択しません。設定がない場合も本文と固定問題を利用できます。

AIには教材本文・現在の質問・直近の会話だけを送ります。質問に個人情報を入力しないでください。アプリから氏名・メール・年齢・他教材の履歴は追加しません。APIキーはブラウザへ渡しません。

## 保持と制限

- 会話は単一プロセスのメモリだけに保持します。再読込後の自動復元は行いません。無操作30分、ログアウト、学習終了、再開始、サーバー再起動で失効します。期限切れ会話は毎分掃除します。
- 学習開始で同じログインの古い会話を置き換えます。同じユーザーでも別ログインから会話へアクセスできません。
- 質問は1件1,000文字、1分3回、ログイン単位で20回まで、同時1件です。通信失敗も回数に含めます。再開始しても上限は戻りません。履歴は直近10メッセージです。
- 期限切れ・ログアウト後の会話は利用できません。タブ復帰時と操作時、AI回答の表示前にも認証・所有権を確認します。
- 保持中の会話は最大100件です。出力は最大1,200トークン、タイムアウトは20秒です。回数制限は利用金額を保証するものではありません。
- 問題の正誤はサーバーの固定ルールで判定し、AIは採点しません。終了表示は習得や正式な受講完了の認定ではありません。

AIの根拠IDが実在することは検証しますが、文章が正しいことの保証にはなりません。本番移行前には教材監修、実回答の評価、本番認証・保存方針・費用管理が必要です。

## 検証

`npm run test:ai-instructor` は教材・会話・認証・AI応答検証のテストです。`npm run test:ai-instructor:browser` は専用の一時JSONコピーとローカル開発サーバーを使い、通常の共有履歴を変更しません。Chromeのパスは `PLAYWRIGHT_EXECUTABLE_PATH` で変更できます。

ブラウザ試験のAI成功経路は通信を置換したUI検証です。実AIは別途、教材内の質問、教材外の質問、命令変更を求める質問を送り、教材との整合性を人が確認します。

接続実装の参照：[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)。Responses APIの構造化出力と `store:false` を使用します。提供先側のデータ取扱いはアプリ内のメモリ保持方針とは別です。

既存の未来ナビの推薦処理とDBスキーマは変更しません。初期版の学習入口は上記URLで、推薦結果からの自動導線は後続の範囲です。
