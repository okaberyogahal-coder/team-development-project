# ミライフ 機能変更一覧

作成日：2026年10月8日  
比較元：添付ファイル「requirements 3 (1).md」  
比較先：これまでの相談を反映した要件定義書 v0.17

## この一覧の見方

優先度（Must・Shouldなど）の変更を除き、利用者ができること、操作手順、システムの動きの違いをまとめる。「元の資料に記載がない」ことは、以前から実装されていなかったと証明するものではない。この一覧は仕様の比較であり、アプリの実装完了報告ではない。

- **追加**：比較元に具体的な機能・ルールの記載がなく、現行仕様で追加したもの。
- **変更**：比較元と現行仕様で動作・利用方式が変わるもの。
- **具体化**：元からある機能について、操作方法や範囲を決めたもの。
- **案・未決**：まだ最終決定していない詳細。確定事項と区別して記載する。

### 予約についての補足

- 予約が必要なのは、開催日時が決まっているリアルタイムのオンライン講座。
- 録画動画や資料を自分のペースで見る学習は、引き続き予約不要。
- 講座以外の一般的な活動・イベント予約まで、今回の講座予約と一括して追加したわけではない。
- 予約締切30分前は確定。予約取消や当日の入室まで、同じ30分前を適用する決定はしていない。
- 講師1人＋受講者7人は初期案。会場割り当てと、当日に予約者が入れるようにする人数管理は詳細設計が必要。

## 3. 機能追加とは分けて扱う整理・明確化

- **4つの機能分類に整理：** 元資料は「学ぶ・教える・つながる・未来ナビ」の説明と6つの詳細機能が併存していた。現行仕様では4分類を軸とする。「スキル習得」などの内容を削除した意味ではなく、学ぶ内容に含める。分類数を建物数や通話室数とは一致させない。
- **シミュレーションを対象外と明記：** 元資料の「体験する」は、料理や職業などを3D操作で再現する機能を明確には要求していなかった。後の相談で制作しないことを確認したため、明記した。既存のシミュレーション機能を削除したという比較にはしない。
- **図書館型の扱い：** 元資料には学習形式として記載がある。現行仕様では教材一覧・資料閲覧に整理され、独立した図書館機能としては具体化されていない。独立施設や専用検索の廃止が決まったとは扱わない。
- **デザインと制作順序：** 先に3D空間を制作し、その空間に合うアバターを作る。従来の配色などは参考案とし、詳細な見た目は後で決める。これは機能追加ではなく制作方針の変更。
- **操作ごとの要件・試験条件：** 入力、成功時、失敗時、権限、再試行などを詳しく定義した。文書が詳しくなった箇所のすべてが新機能というわけではない。
