# スキルメモリー（Skill Memory）構想

## 1. 位置づけ

- 状態：採用案
- 対象：ミライフ（MIRAI LIFE）の未来感を担う中核候補機能
- 目的：単なる教材閲覧・オンライン授業ではなく、「人が身体で身につけた技能・経験」を次世代へ継承できる学習体験を作る
- 現段階：企画・設計方針。既存のMust要件へ即時統合するのではなく、実装可能性を確認しながら詳細要件へ落とし込む

## 2. 背景

現在のミライフには、教材・動画、オンライン講座、交流、AI未来ナビなど、既存サービスでも実現可能な要素が多い。

未来創造展の「100年後の未来」というテーマに対して、既存システムの組み合わせだけでは未来感が弱く見える可能性がある。

一方、今後AIによって文章・画像・プログラムなどの「情報生成」は急速に自動化されると考えられる。将来は、知識そのものを得ることよりも、人間が長年の経験によって身につけた身体的な技能や暗黙知を、どう記録し、次世代へ引き継ぐかが重要になると想定する。

そこでミライフでは、動画を見るだけの学習から一歩進み、実際の身体動作をデータ化して、別の利用者がその技能を再現・練習できる仕組みを検討する。

## 3. コンセプト

### 人間の「技能」を、映像ではなく再利用できるデータとして残す

現在：

先生が実演する  
→ 動画として保存する  
→ 学習者が動画を見て真似する

未来：

先生が実演する  
→ 身体の動き・姿勢・角度・速度・順序・説明を取得する  
→ Skill Dataとして保存する  
→ 学習者が実際に動く  
→ システムが先生のSkill Dataと比較する  
→ リアルタイムに修正点を伝える  
→ 習得履歴を残す

ミライフでは、この仕組みを「スキルメモリー（Skill Memory）」と呼ぶ。

## 4. 未来の社会設定

将来、生成AIや自動開発技術が進歩し、一般的な知識・文章・画像・ソフトウェアなどは短時間で生成できるようになると想定する。

その一方で、次のような技能は単純な文章だけでは完全に伝えにくい。

- 料理の手さばき
- 包丁の使い方
- 職人の道具の扱い
- スポーツのフォーム
- 楽器演奏の姿勢
- 介護時の身体の支え方
- 農作業の動作
- 製造・整備の手順
- 身体を使う趣味・技術
- 長年の経験による「感覚的なコツ」

このような技能は、熟練者が引退したり、教える機会を失ったりすると、その人の中に蓄積されたまま失われる可能性がある。

そこで未来のミライフでは、人の身体技能をデータとして記録し、別の世代へ受け渡す。

## 5. システムの基本構成

### 5.1 教える側

1. 利用者が「教える技能」を選択する
2. Webカメラまたはカメラの前で技能を実演する
3. システムが身体の骨格・関節位置・角度・動作順序などを取得する
4. 利用者が音声または文章でコツ・注意点を追加する
5. 動作データと説明をSkill Dataとして保存する
6. ミライフ内で公開する

### 5.2 学ぶ側

1. ミライフ内で学びたい技能を選択する
2. お手本となるSkill Dataを表示する
3. 利用者がカメラの前で同じ動作を行う
4. システムがリアルタイムで骨格を取得する
5. お手本との角度・位置・動作順序などを比較する
6. 差が大きい部分を画面上で案内する
7. 練習結果を保存する
8. 次に学ぶ技能をAI未来ナビが提案する

## 6. 体験イメージ

### 例1：体操・ストレッチ

先生：
- 右腕を上げる
- 左腕を横へ伸ばす
- 体を傾ける

学習者が実演すると、画面に以下を表示する。

- 右腕：一致度 92%
- 左腕：一致度 64%
- 姿勢：78%
- 「左腕をもう少し上げてください」

### 例2：職人技能

熟練者が作業の基本動作を記録する。

- 手の位置
- 道具の角度
- 動かす順番
- 動作速度
- 本人によるコツの説明

若い利用者は、保存されたSkill Dataを使って練習できる。

### 例3：世代間継承

70歳の利用者が自分の得意な技能を記録する。

↓  

Skill Dataとしてミライフへ保存

↓  

数年後・数十年後に別の利用者が学ぶ

「人から人へ直接教える」だけでなく、「人からデータへ残し、未来の人へ渡す」ことができる。

## 7. 未来感を出しているポイント

### 7.1 動画を保存するのではなく、技能をデータとして保存する

現在の動画教材では、見る側が自分で正しいか判断する必要がある。

スキルメモリーでは、先生の身体動作を数値・骨格データとして保存し、学習者の動きと直接比較する。

### 7.2 仮想空間だけで完結しない

ミライフ内で教材を見るだけではなく、現実世界で利用者が実際に身体を動かす。

ミライフ  
→ 現実世界で実践  
→ カメラで動作取得  
→ 結果をミライフへ戻す

という循環を作る。

### 7.3 人の経験を次世代へ残す

人がいなくなった後でも、その人が残したSkill Dataから学べる未来を想定する。

単なるオンライン授業ではなく、「技能の保存・継承」が目的になる。

### 7.4 将来的には個人の身体に合わせて技能を変換する

完成形では、お手本をそのままコピーするだけでなく、

- 身長
- 手足の長さ
- 年齢
- 身体能力
- 可動範囲

などに応じて、その人向けの動きへ補正する。

例：

先生：身長180cm  
学習者：身長155cm

→ 完全に同じ位置を要求するのではなく、身体比率に合わせて目標角度・位置を調整する。

## 8. 現在の技術で作る試作版

未来の完成形をすべて作る必要はない。

展示では、「身体技能をデータとして保存し、別の人の動作と比較できる」ことを実証する。

### MVP案

題材：
- 体操
- ストレッチ
- 簡単なダンス
- 決められたポーズ
- 簡単な手作業のフォーム

必要技術：

- Webカメラ
- MediaPipe Pose等の骨格推定
- JavaScript / TypeScript または Python
- Next.js
- 必要に応じUnity連携
- PostgreSQL等への記録保存

取得候補：

- 肩
- 肘
- 手首
- 腰
- 膝
- 足首
- 各関節の角度
- 動作開始・終了
- 動作の順序

### 最低限のデモ

1. 先生役がお手本ポーズを登録
2. 骨格データを保存
3. 学習者が同じポーズを取る
4. 関節角度を比較
5. 一致度を表示
6. 誤差が大きい部位を表示

これだけでも「映像を見るだけではなく、技能データと自分の身体を比較して学ぶ」というコア体験を示せる。

## 9. ミライフ既存機能との接続

### 学ぶ

教材詳細から「Skill Memoryで練習」を開始する。

### 教える

教材・動画投稿に加えて、技能データを登録できる。

### つながる

先生と学習者が同じ交流室で話しながら、Skill Dataを使って指導できる。

### AI未来ナビ

受講履歴だけでなく、

- 練習した技能
- 苦手な動作
- 習得度
- 興味

などを参照し、次の技能を提案する。

## 10. 3D空間との関係

3D空間を単なる交流用の背景として使うのではなく、技能学習への入口として利用する。

例：

ミライフ広場  
→ 技能エリアへ移動  
→ 「園芸」「運動」「料理」などの技能を選ぶ  
→ Skill Memoryを起動  
→ 現実世界で実際に動く  
→ 結果を保存  
→ 広場へ戻る

これにより、3D空間と現実世界の体験をつなぐ。

## 11. 既存のAI未来ナビとの違い

AI未来ナビ：
- 次に何を学ぶかを提案する

スキルメモリー：
- 実際に身体を使って技能を練習する
- 先生の動作と比較する
- 技能そのものを保存する

役割を混同せず、

AI未来ナビ = 「次に何をするか」

スキルメモリー = 「どう身につけるか・どう残すか」

と整理する。

## 12. 対象外・注意点

初期試作では以下を目的にしない。

- 実際の資格認定
- 医療行為の判定
- 危険な作業の自動指導
- 職人技能を完全再現すること
- 力加減・触覚の完全な再現
- 全身モーションキャプチャ専用機器の導入
- 「技能を習得した」とシステムだけで断定すること

あくまで未来構想を体験できるプロトタイプとして制作する。

## 13. 将来拡張

将来的には次の発展を想定する。

### 13.1 力加減の記録

圧力センサー・グローブ等を利用し、姿勢だけでなく力の情報を保存する。

### 13.2 触覚情報

触覚デバイスによって、押す・引く・握るなどの感覚を伝える。

### 13.3 3D動作データ

複数カメラや深度センサーを使って、より正確な3Dモーションとして保存する。

### 13.4 個人最適化

利用者の体格・年齢・身体能力に合わせ、お手本動作を補正する。

### 13.5 遠隔指導

リアルタイム通話と組み合わせ、先生が遠隔地から学習者の動きを確認する。

### 13.6 技能の世代継承

長期間保存されたSkill Dataを、次世代・さらに次の世代が利用できるようにする。

## 14. ミライフ全体への意味

ミライフは「教材を見るオンライン学習サービス」だけではなく、

**人が人生の中で得た知識・経験・技能を、世代を超えて循環させる場所**

を目指す。

スキルメモリーは、その中でも「文章や動画だけでは残しにくい身体技能」を扱う。

現在：

人 → 人

将来：

人 → Skill Data → 人

という新しい知識継承の形をミライフの未来性として示す。

## 15. 一言で説明する場合

> スキルメモリーは、人が長年かけて身につけた身体技能を動作データとして保存し、別の利用者が自分の動きと比較しながら学べる、未来型の技能継承システムです。
