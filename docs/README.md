## 現在の整理

現在は、資料を次の3種類に分けて管理する。

| 種類 | ファイル | 目的 |
|---|---|---|
| 見やすい版 | `requirements.md` | 発表・確認用に全体像を読む |
| 詳細版 | `requirements-detail-v0.17.md` | 操作条件・受入条件まで確認する |
| 変更一覧 | `feature-change-list.md` | 元資料からの変更点を説明する |

## 注意点

- `requirements.md` は読みやすくまとめた版なので、細かい条件は省略されている。
- 詳細な操作要件や受入条件は `requirements-detail-v0.17.md` を確認する。
- `feature-change-list.md` は要件そのものではなく、変更点を説明するための資料である。
- 2D版の実装状況と、Unity 3D・実AI・予約制講座などの完成版要件は区別して読む。
- LiveKitのAPIキーやシークレットなどの秘密情報は、ドキュメントに書かない。

## おすすめの読み方

1. まず `requirements.md` でサービス全体を理解する。
2. 変更点を説明したい場合は `feature-change-list.md` を見る。
3. 実装する機能が決まったら `requirements-detail-v0.17.md` で細かい条件を確認する。
4. ミライフ広場や通話を確認する場合は `metaverse-design.md` と `plaza-testing.md` を見る。
