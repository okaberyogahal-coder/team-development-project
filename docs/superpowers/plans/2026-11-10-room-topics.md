# Room Topics Implementation Plan

**Goal:** 4つの交流室に各5題のテスト用お題を挿入し、入室後に選んで会話に使えるようにする。

**Architecture:** 現在のUnityワールドへJSONの固定カタログを同梱する。部屋ごとのお題選択は実行中に保持し、既存の入室・退出とパネルへ接続する。現状は部屋のサーバー連携がないため、共有DBや他の参加者への同期を追加する方式ではなく、取得後すぐ使える同梱データ方式を採る。

**Tech Stack:** Unity 6000.4.2f1 / C# / Resources JSON / NUnit / WebGL。

## Constraints

- 交流カフェ、趣味、学び、経験共有に各5題。架空の会話のお題で、個人情報やアカウントは作成しない。
- お題本文、3つの会話のヒント、別のお題を選ぶ操作を提供する。
- 既存の部屋、人物、認証、アバター、歩行修正を保持する。
- 回答の入力・投稿や通話の実接続、選択内容の他者への同期は対象に含めない。

## Tasks

- [x] 同梱お題の欠落を検知するテストを作成し、失敗を確認する。
- [x] JSON20題と部屋別の選択ロジックを実装し、選択・循環・部屋間の独立性を検証する。
- [x] 入室、部屋のお題ボタン、選択パネル、退出へ接続する。
- [x] Unityテスト、Webテスト、WebGL生成、ブラウザ上の入室・選択・再選択・退出を確認する。

## Review focus

部屋IDの不一致、選択の部屋間混入、パネル終了後の移動復帰、短い画面でのスクロール、データ未読込時の表示。
