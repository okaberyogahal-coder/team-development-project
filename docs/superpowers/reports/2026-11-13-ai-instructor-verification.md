# AI講師ローカル検証版：実装・検証結果

## 実装範囲

`/ai-instructor` にサンプル教材「自然光と背景ぼけの基本」の本文、節選択、AI質問・やさしい説明・具体例、根拠節への移動、固定三択問題3問と復習を追加した。専用起動コマンドは `npm run dev:ai-instructor`。アクセス先は `http://localhost:3004/ai-instructor` で、既存のローカルログインを使用する。

会話・採点はサーバーが管理する。会話を永続保存せず、所有トークン、期限、連番、回数制限を検証する。ログアウト・学習終了・再開始で会話を失効する。AI未設定や通信失敗時にも本文と確認問題を利用できる。

本番公開、音声・アバター、DB変更、正式な受講完了記録、未来ナビからの自動連携は含まない。

## レビューと修正

独立レビューで、回答待ち中のタブ復帰がPOSTを中断し、古い連番が残る問題を検出した。再現テストが失敗することを確認したうえで、処理中のPOSTを保持し、権限再確認と単調な状態反映、送信前の連番同期を実装した。回帰テストは成功した。通信失敗後もサーバー状態を再取得するため、消費済み回数と表示が同期する。

生成済み `.next/types` に以前の `* 2.ts` コピーが存在し、型定義が重複していた。無視対象の生成ファイルのみ `/private/tmp/melife-next-type-duplicates-upa68gmh` へ退避し、型チェックを再実行して成功した。アプリのソースや無関係な未追跡ファイルは変更していない。

## 実AIの確認結果と残る作業

サーバーのキー・モデル設定があることだけを確認し、教材内質問、教材外質問、指示変更を求める質問の実AI確認を開始した。最初の要求に対し、提供先はHTTP 401 / `expired_secret_key` を返したため、実AIの回答・教材整合性・命令変更への耐性は未検証。キーの値は表示・記録していない。

有効な `OPENAI_API_KEY` をサーバーの `.env.local` に設定して再起動した後、上記3種類の質問で実回答を確認する必要がある。ブラウザ試験の成功を実AI接続成功とは扱わない。本番移行前には教材監修、会員認証・権限、保持・削除方針、利用金額管理が必要。

操作方法は `docs/ai-instructor.md` を参照。
