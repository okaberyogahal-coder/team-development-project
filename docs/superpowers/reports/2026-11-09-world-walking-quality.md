# ワールドの歩行と画質の検証

## 変更

- 現在の`/plaza`は`/unity/FutureCity/index.html`を使用する。V3の実装元は`Assets/MelifeAvatarV3/Runtime/MiraifuRuntimeAvatar.cs`で、メンバーの別ディレクトリへの歩行修正は自動では反映されていなかった。
- 歩行クリップの終端を超えた時刻を、余りの時間を保って先頭へ戻す。元のクリップや外見の素材は変更しない。
- アニメ調のMSAA 4xは維持し、追加の全画面SMAAを外す。描画解像度・街の素材・影の設定を落とさない。輪郭は比較画像で明瞭になったが、硬い影のギザギザが見えやすくなる点は残る。
- WebGLを再生成し、ローカルの`public/unity/FutureCity/Build/FutureCity.*`へ反映。これらの生成物は既存のGit除外対象。元の生成物は`/private/tmp/melife-world-build-before-20261109`へ退避した。

- 修正前は、歩行クリップ3周期後の位相検証が失敗した。
- Unity 6000.4.2f1：6体の位相検証、実行モードで3周期後も骨が動く検証、MSAAと等倍描画の検証を含む43件が成功。
- `npm test`：125件成功、失敗・スキップ0件。
- WebGLビルド：終了コード0。
- Chromeで本物のWebGLとV3外見を使用し、約4秒の連続歩行で約14m移動、異なる脚・腕の姿勢を画像で確認。ブラウザ例外0件。アカウントはブラウザ内のセッション応答だけを架空の値に置換し、DBへ登録していない。
- コードレビュー：重大な指摘なし。Unityが検証中に更新したパイプライン・品質設定は差分へ含めない。
