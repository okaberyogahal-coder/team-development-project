# ミライフ — 3D広場（Unity）　仕様 v0.17 対応版

**「何歳からでも、新しい未来へ挑戦できる人生アップデート空間」** を、シニアの方が
「行ってみたい」と思える、明るくおだやかな未来の庭園キャンパスとして作りました。
空間・案内・画面は C# スクリプトで生成し、素材には **実写（CC0）のテクスチャ** と **実写の 360°写真** を使います。

- **まわりの景色は実写の写真**です（街をCGで作るのをやめ、その分を広場の質感に回しました）。写真は自由に差しかえられます。
- 夜はありません（昼に固定）。明るい白・クリーム色・やさしい花の色を中心にしています。
- 文字は大きく（本文22px相当以上）、ボタンも大きく（高さ56px以上）、点滅やちらつきはありません。
- マウスだけで操作できます（地面をクリックするとそこまで歩きます）。

---

## セットアップ（3ステップ）

ZIP は容量の都合で **2つ** に分かれています（どちらも必要です）。

1. Unity Hub で **Universal 3D（URP）** テンプレートの新規プロジェクトを作る（Unity 6 推奨）
2. 2つの ZIP をそれぞれ展開し、次の **2つのフォルダ** をプロジェクトの `Assets` にドラッグ
   - ZIP 1（`FutureCity_Unity_1of2.zip`）の `FutureCity\Assets\` の中の **FutureCity** フォルダ（プログラムと素材）
   - ZIP 2（`FutureCity_Unity_2of2.zip`）の `FutureCity\Assets\` の中の **FutureCityPhotos** フォルダ（360°写真と一部の素材）
   （**以前の版を入れている場合は、先に `Assets/FutureCity` を削除してください**）
3. メニュー **Tools > Future City > Create Scene** → **▶ Play**

- 今回から素材（テクスチャ・写真）が入ったため、**必ず Create Scene をやり直してください**（古いシーンのままだと素材が正しく読み込まれません）。
- 初回の Create Scene は、テクスチャの取り込み（圧縮）で **1〜3分ほど** かかることがあります。

```
                     ＼        ｜        ／
  教える ─────────── ロビー（噴水・花壇・ベンチ） ─────────── 学ぶ
```

| 場所 | 内容（仕様との対応） |

## まわりの景色（実写の 360°写真）

- 空と遠くの景色は、`Assets/FutureCityPhotos/Resources/FutureCityBackdrop/` の **360°写真**（横:縦 = 2:1）です。
  同梱の写真は、夏の雲のある青空と木立の実写（Poly Haven「Parched Canal」・CC0）です。
- Play のたびに写真を自動で解析して、次をそろえます。
  - **太陽**：写真の中の太陽を見つけ、太陽の光の向き・色を合わせる（影の向きが写真の太陽と一致）。さらに、太陽が広場を斜め後ろ（南東）から照らす向きに写真を回す
  - **明るさ**：空の明るさを自動調整（Inspector の Backdrop Exposure で微調整）
  - **環境光**：空の色から日かげの青み・地面の照り返しを作る（太陽そのものは除く）
  - **かすみ**：湖の遠くを、写真の地平線の色になじませる
- 地平線より下は湖の水面になるので、写真の地面は見えません。

### 写真を街の写真に変える（おすすめ）

1. Poly Haven の **「Modern Buildings 2」**（川ぞいの広場とガラスのビル・晴れ・CC0）を開く：https://polyhaven.com/a/modern_buildings_2
2. ダウンロードで **HDR の 4K**（よりくっきりは 8K）を選ぶ（「Tonemapped JPG」でも使えます）
3. Unity のメニュー **Tools > Future City > 背景の写真を入れるフォルダを開く** → 開いたフォルダにそのファイルを入れる
4. **▶ Play**。あなたが入れた写真が、同梱の写真（`Default_` で始まる名前）より優先して使われます

ほかの候補：「Canary Wharf」（ロンドンの高層ビル街）https://polyhaven.com/a/canary_wharf 。スマホなどで撮った 360°写真（JPG）も使えます。

**ダウンロードなしで試せる別の写真**：`Assets/FutureCityPhotos/BackdropAlternatives/FlowerRoad_2k.hdr`（遠くに山なみが見える、雲のない晴天の写真）を、
Unity の Project ウィンドウで `Resources/FutureCityBackdrop` フォルダへドラッグして移動 → ▶ Play。広い湖と山の景色になります（元に戻すときは移動し直す）。
写真の向きを自分で決めたいときは、`FutureCity` オブジェクトの Inspector で **Auto Rotate Backdrop** をオフにして **Backdrop Rotation** を変えてください。
**Photo Backdrop** をオフにすると、以前のCGの未来都市に戻ります。

## 広場の質感（今回強化したところ）

| 部分 | 内容 |
|---|---|
| 素材 | 石畳・白い石・芝生・木・樹皮・金属・土・布に、**実写テクスチャ**（色＋凹凸の法線マップ＋つや・金属・すき間の陰のマスク） |
| 形 | ベンチ・花壇・壁・道などの**角を少し丸めて**、光がやわらかく当たるように |
| 木 | 幹と枝は樹皮の質感、葉は **葉を描いた板を数百枚重ねて**ふんわり。木もれ日のような影が落ちる。桜・糸杉・低木も同じ作り |
| 花 | 花壇・花畑・野の花を**本物らしい花の絵**で。藤棚には**垂れ下がる藤の花房** |
| 芝生 | 芝生の上だけに**立体的な草**を約8万株（道・花壇・建物の上には生えない）。遠くの草は自動で描かない |
| 水 | 噴水・池・湖に**2つの波を重ねて流れる**水面。空と広場が映り込む。池の底は土 |
| 人 | 服に**布目の質感** |
| 光 | 写真の太陽と空から作る光、4096 の影を広場（150m）に集中、反射プローブ |

## 操作方法

| 操作 | 内容 |
|---|---|
| **マウスを動かす** | まわりを見る（**ボタンは不要**） |
| W A S D ／ 矢印キー | 歩く（Shift で速く） |
| **1〜6 キー** | 下のメニュー：**1** 学ぶ／**2** 教える／**3** つながる／**4** 未来ナビ／**5** プロフィール／**6** ヘルプ |
| 画面中央の点で指して左クリック | 人に話しかける・そこまで歩く |
| **E** ／ Enter | 近くの入口を「ひらく」・部屋に「入室する」・人のプロフィールを見る |
| ホイール ／ Q・E | 近づく・離れる ／ 左右に回る |
| **R** | 視点をもとに戻す |
| **Esc** | マウスカーソルを出す（画面をクリックすると見回しに戻る）。画面を開いているときは閉じる |
| V | 見回しモードのオン・オフ |

メニューや画面を開いている間は、自動でマウスカーソルが出てボタンを押せます（その間は歩きません）。閉じるとまた見回しに戻ります。
画面下のボタンには番号がついていて、マウスで押すこともできます。

## 確認したこと

- 3通りの設定（URP＋新Input System＋TAA／URPのみ／Built-in＋旧Input）で、全ファイルのコンパイルを確認（警告なし）
- 写真の計算：写真の座標→空の方向が Unity の Skybox/Panoramic シェーダーと一致（誤差 0.000001）、自動回転で太陽が目標の方角へ（誤差 0.0001°）、HDR／JPG の写真で太陽の位置を検出、環境光の強さの単位が Unity と一致（一様な空→1、上半分の空→上1・下0・横0.5、小さな光源→理論値と一致）など 14件すべて合格
- 同梱の写真の解析結果：太陽の高度 34°、明るさ ×2.8、日なたと日かげの明るさの比 約3.2（日なたの白い面がほぼ白、日かげは空の青み）
- 形：湖・陸地・遊歩道・ガラスの手すり・角を丸めた箱の面の向き（裏返りなし）をすべて確認
- 予約締切：14:00開始なら 13:29:59 は予約可、**13:30:00 ちょうど以降は不可**、満席・中止・自分が講師の回は不可
- 未来ナビ：最大3件、公開教材だけ、自分の教材と受講済みは出さない、0件なら理由を返す、**同じテーマばかりにしない**
- 上記を含む規則の単体テスト19件を実行し、すべて合格（Unity外のC#実行環境で確認）
- キャンパス：入口・交流室・デモ人物の位置（壁や噴水と重ならない）

Unity 上での実際の見た目・動作速度は未確認です。気になる点があれば教えてください。

## 画質と滑らかさ

- アンチエイリアスは **TAA**（葉や草のふちのギザギザ・ちらつきも消える）。オフにすると MSAA 4x＋SMAA。
- 4096の高解像度の影（広場の周辺150mに集中・4段カスケード）、512の映り込み、HDR・ACES・Bloom（写真の太陽のまぶしさは上限つき）。
- 垂直同期で画面のリフレッシュレートに合わせて表示し、カメラの向き・距離・高さはなめらかに追従します（段差や木・街灯・人でガクッと動かない）。
- **Unityエディタで見るときは、Game タブ上部の解像度を「1920x1080」などにし、Scale を「1x」にしてください。**「Free Aspect」で小さく表示したり拡大表示したりすると、画面がぼやけたりカクついて見えたりします。
- さらにくっきりさせたいときは、Inspector の **Render Scale** を 1.25〜1.5 に（重くなります）。重いときは 1.0 のまま `Realtime Reflections` をOFFに。

## カスタマイズ

シーンの `FutureCity` オブジェクトの Inspector：背景の写真（Photo Backdrop・明るさ・向き）、歩く速さ、まわりを見る速さ、
TAA・立体的な草・歩く人・反射・ポストエフェクトの有無。都市モード（Photo Backdrop オフ）では、シード・街の大きさ・交通量・**昼の時刻（7〜16時）**。

```
│   └── Systems/                 … 歩行と視点・背景の写真（PhotoBackdrop）・水面・映像効果・（都市モードの）交通・リニア・昼の光
├── Resources/
│   └── FutureCityTextures/      … 広場の実写テクスチャ（CC0）
├── Editor/
│   ├── FutureCityMenu.cs        … シーン自動作成メニュー
│   └── FutureCityImport.cs      … テクスチャ・写真の取り込み設定を自動でそろえる
└── CREDITS.md                   … 素材のクレジット（すべて CC0）

Assets/FutureCityPhotos/         … ZIP 2 の中身
├── Resources/FutureCityBackdrop/ … 背景の 360°写真（ここに自分の写真を入れる）
├── Resources/FutureCityTextures/ … 広場の実写テクスチャの残り（芝生・土・樹皮の凹凸）
└── BackdropAlternatives/        … 予備の 360°写真
```
`Resources` という名前のフォルダは、Assets の中のどこにあっても Unity がまとめて読み込むので、2つのフォルダに分かれていても大丈夫です。
