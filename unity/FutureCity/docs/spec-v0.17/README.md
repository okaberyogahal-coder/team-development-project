# ミライフ 共通仕様パッケージ v0.17

2026-10-08。制作メンバーと各自のAIで、目的・優先度・ユーザー操作・詳細度を合わせるための文書です。

## まず読むもの

全員のAIには、**AI_INSTRUCTIONS.md**と**mirailife-ai-reference.md**の2ファイルを同じ版で渡してください。統合参照版に下記の本文をまとめたため、フォルダを全部開く必要はありません。最初は統合版の「共通認識の要約」「要件定義の1〜5節」「未決事項」を読むと全体をつかめます。

## チームでの使い方

1. 全員が同じv0.17の共通指示と統合版を読む。
2. AI理解確認の質問を試し、誤読した優先度や未決事項を修正する。
3. タスクをFR番号で指定し、操作ごとの共通項目と受入条件まで出力してもらう。
4. 未決事項を決めたらdecisionsと該当文書を更新し、統合版も作り直して全員へ同じ版を配る。

未決の方式・提案値を確定として扱わないでください。文書の詳細化は実装・試験済みの保証ではありません。審査用台本や機能縮小計画は今回の中心にしていません。

## v0.16の主な変更

- 未来感を優先する3D背景＋統一Webパネルを委任により採用。
- 年齢はv0.17で実年齢公開へ変更。旧非公開の記述はDEC-029で置換。資格登録を追加。
- 一般自由登録を確定。通報・教材停止はShouldへ確定（v0.16）。
- FR-314／315と関連試験、データ・通信、AI指示を同期。旧v0.12を混ぜず同じ版を全員へ渡す。

v0.16追加：通報・教材公開停止をShouldへ変更。18歳未満の保護者確認を採用し、登録・利用権限・非公開データ・試験へ反映。プロフィール年齢とAI利用設定とは別の用途で扱う。

v0.16変更：挑戦の理解が一致、3D内シミュレーションは対象外。先に3D空間を制作し、それに合うアバターを制作する方針を反映。外観の細部は後から決め、過去の配色案を固定条件にしない。

v0.16（2026-10-08）：予約制オンライン講座をMustへ変更。予約締切は開始30分前に固定し、個別設定は不要。内容・開催回・予約・定員・予定・中止・当日参加を操作単位で追加。動画・資料の自由閲覧は維持。取消・遅刻・会場枠の条件は未決。

v0.17（2026-10-08）：プロフィールに実年齢（54歳なら54歳）を表示し、資格登録を追加。年齢の公開とAI利用設定を分離。資格は自己申告・複数件登録を初期案とし、必須保有や認定は追加しない。
