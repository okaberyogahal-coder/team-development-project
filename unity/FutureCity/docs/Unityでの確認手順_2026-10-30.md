# Unity での確認手順（2026-10-30 版）

この版は、Unity エディタ本体では動かしていません（作業環境に Unity がないため）。
コードのコンパイル・生成処理の実行・シェーダーのコンパイル・見た目のプレビューは確認済みです（`docs/グラフィック改修レポート_2026-10-30.md` の「検証」）。
お手元の Unity で、次の手順で確かめてください。

---

## 1. 入れかえ（5 分）

1. **今のプロジェクトを保管**：プロジェクトのフォルダごとコピーしておく（元にもどせるように）。
2. Unity でプロジェクトを開き、Project ウィンドウで **`Assets/FutureCity` と `Assets/FutureCityPhotos` を削除**。
3. 3 つの ZIP を展開し、次のフォルダを `Assets` にドラッグ。
   - ZIP 1：`FutureCity\Assets\` の中の **FutureCity**（プログラム・シェーダー・モデル）
   - ZIP 2：`FutureCity\Assets\` の中の **FutureCityPhotos**（従来の 360°写真と一部の素材。実写風のときに使用）
   - ZIP 3：`FutureCity\Assets\FutureCity\Resources\` の中の **FutureCityTextures** を、`Assets/FutureCity/Resources/` の中へ（実写風のテクスチャ）
4. 取り込みが終わるまで待つ（シェーダーとテクスチャの取り込みで **数分** かかることがあります）。
5. メニュー **Tools > Future City > Create Scene** を実行（**必ずやり直してください**）→ **▶ Play**。

## 2. まず見てほしいところ（チェックリスト）

| | 確認すること | うまくいっていれば |
|---|---|---|
| 1 | Console（Window > General > Console）に赤いエラーがないか | エラーなし。`[FutureCity] アニメ調のモデル：○個` などの情報が出る |
| 2 | ピンク色（マゼンタ）の物体がないか | ない（あればシェーダーのエラー。下の「困ったとき」へ） |
| 3 | 空 | 青いグラデーションに白い積雲、遠くに緑の丘と白い塔 |
| 4 | 中央広場 | 噴水・光る輪の彫刻・曲面のベンチ・植木鉢・花壇。影が灰色でなく青紫寄りで明るい |
| 5 | 人物 | 顔（大きな目・まゆ・口）、髪型、服の縁どり。ベンチに座る人はひざが曲がっている |
| 6 | 交流室 | 角の丸い白い建物・ガラス・屋上の植え込み・入口のひさし。中に入ると家具 |
| 7 | 戦闘モード | F → 画面上に案内と照準。左クリックでビーム、右クリックで肩ごしにズーム、E でパンチ、Enter で話せる。もう一度 F でもどる |
| 8 | 動き | 歩く・見回す・クリックで歩く（戦闘モード以外）・1〜6 のメニュー・入室・未来ナビがこれまでどおり |
| 9 | 速さ | Game タブ右上の **Stats** で FPS（目安 60 前後） |

Game タブは解像度を「1920x1080」など、Scale を「1x」にして見てください（小さい表示・拡大表示だと、ぼやけたりカクついて見えます）。

## 3. 画質の設定（任意）

- **やわらかい陰影（SSAO）**：Create Scene のときに自動で追加します。できなかったときは、Project の Settings フォルダの「PC_Renderer」→ Add Renderer Feature → Screen Space Ambient Occlusion。
- **アンチエイリアス**：アニメ調では自動で MSAA 4x＋SMAA（細い輪郭線がくっきり）。
- **影**：URP のアセット（Settings フォルダの PC_RPAsset など）で Shadow Resolution を 4096 にすると、人物の影がくっきりします（重くなります）。
- `FutureCity` オブジェクトの Inspector：
  - **Anime Style**：オフで従来の実写風（360°写真の背景）
  - **Combat Mode**：オフで戦闘モードを無効に
  - **Lawn Grass**／**Ambient People**／**Render Scale**／**Post Processing**：重いときに調整
- 空・光・霧・風は、Play 中に `FutureCity` オブジェクトに付く **Mirai Atmosphere** コンポーネントの値を変えるとすぐ反映されます（太陽の高さ・方位、空の色、影の側の明るさ、霧の濃さ、風の強さ）。気に入った値は Play を止める前にメモしてください（Play を止めると元にもどります）。

## 4. 困ったとき

| 症状 | 対処 |
|---|---|
| 物体がピンク色 | シェーダーがコンパイルできていません。Console の赤いエラー（`MiraiToon/...` の行）をコピーして送ってください。とりあえず見るだけなら Inspector の Anime Style をオフ |
| 全体が実写風のまま | Console に「アニメ調のシェーダー（MiraiToon）が使えないため…」と出ていないか。URP のプロジェクトか（Built-in では実写風になります）。`Assets/FutureCity/Resources/FutureCityShaders` があるか |
| 人物が球と円柱のまま | `Assets/FutureCity/Resources/FutureCityModels` に `Chr〜.bytes` があるか |
| 雲がない・空が単色 | `Assets/FutureCity/Resources/FutureCityAnime/MT_Clouds.png` があるか。取り込み設定（Editor/FutureCityImport.cs が自動で設定）を変えていないか |
| 重い | Lawn Grass・Ambient People をオフ、Render Scale を 1.0 以下に |
| 戦闘モードの照準がずれる | Esc でカーソルを出しているときは、照準はマウスの位置になります。画面をクリックすると見回しモード（照準は画面中央）にもどります |
| 効果音が聞こえない | シーンに Audio Listener（Main Camera に付いています）があるか、Game タブの「Mute Audio」がオフか |

## 5. ビルド（アプリにする）

シェーダー・モデル・テクスチャは `Resources` フォルダにあるので、そのままビルドに含まれます。
File > Build Profiles（または Build Settings）で、Create Scene で作った `Assets/FutureCity/Scenes/FutureCity.unity` が一覧の先頭にあることを確認してビルドしてください。

## 6. お知らせいただけると助かること

- Console のエラー・警告（あれば全文）
- 気になった場所のスクリーンショット（Game タブ）
- FPS（Stats の値）と、パソコンの GPU の名前

いただいた内容をもとに、見た目と速さを調整します。
